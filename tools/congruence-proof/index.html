中2 · 平行と合同

合同の証明をつなごう。

ABとCDが等しい理由を説明しよう。

仮定：2直線ACとBDが点Oで交わる。

OA = OC かつ OB = OD

対頂角が等しい理由

∠BOCを使うと、どちらの角も同じ式になります。

∠AOB = 180° − ∠BOC
∠COD = 180° − ∠BOC

A・O・C、B・O・Dが、それぞれ一直線だからです。

つながった証明

△AOBと△CODにおいて、

  1. OA = OC仮定
  2. OB = OD仮定
  3. ∠AOB = ∠COD対頂角は等しい

2組の辺とその間の角が
それぞれ等しいので、

△AOB ≡ △COD

合同な図形の対応する辺は等しいので、

AB = CD

図の見た目や長さの測定に頼らず、仮定から結論までつなぎました。

図を変えて確かめる

図を変えても、仮定と証明は変わりません。

長さは1〜5、角度は20°〜160°。三角形がつぶれる図は作りません。図全体の表示倍率は自動で調整します。
